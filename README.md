# 鲜知 FreshKeeper 🥬

家庭食材保质期决策助手：录入食材 → 自动计算该先吃谁 → 临期给出明确建议
（尽快食用 / 分装冷冻 / 建议丢弃）→ 用现有库存组合简单做法 → 所有修改与处理全程可追溯。

纯前端实现：**无需注册、无需服务器、数据只存在本机浏览器**。手机浏览器打开即可用，
支持拍照识别包装标签（识别结果需手动确认才会保存）。

## 快速开始

```bash
cd freshkeeper
npm start                 # 然后浏览器访问 http://localhost:8080
```

或直接双击打开 `index.html`（拍照识别需要联网加载一次 OCR 组件，其余功能离线可用）。

第一次使用可点右上角 ⚙️ → **载入演示数据**，立刻看到过期/临期/冷冻等各种状态。

## 主要功能

- **库存清单**：按处理优先级排序，红/橙/绿色标一眼看出“先处理谁”，可按过期、尽快、冷冻中等筛选。
- **明确建议**：点进食材可见“建议丢弃/尽快食用/冷冻中时钟暂停/品质下降”等结论、剩余天数和理由。
- **改变期限的记录**：已开封、放入冷冻、解冻、做熟、重新加热、移常温、吃完、丢弃——
  一键记录，期限立即重算（如开封后酸奶按 3 天计；复热不会“刷新”保质期）。
- **拍照录入**：拍包装标签自动识别品名、到期日、贮存条件，**回填表单由你确认**后才入库。
- **组合方案**：可勾选指定几样食材，系统按库存匹配家常做法；每个方案都写明
  「使用了哪些食材」和「做完后还有哪些需要尽快处理」，一键执行后自动写入处理记录。
- **用餐计划**：从库存勾选食材（或把方案一键带入）安排到某一天，创建时按**计划日预计状态**
  提示调整（临期/已过期/需提前解冻）；计划清单按日期排列，点「标记完成」逐样记录
  做熟/吃完/丢弃（沿用库存事件体系），计划状态与追溯流水自动更新。
- **家庭成员饮食偏好与忌口/过敏**：为每位成员记录过敏食材（按分类或自定义关键词，如水产、花生）、
  忌口/不喜欢和偏好/爱吃。在**方案页**或**新建用餐计划**时选择就餐成员，系统对库存与方案中的食材
  逐样给出明确冲突提示：🚫 过敏为阻断级（红色，必须处理）、⚠️ 忌口为警告级、💚 偏好为正向提示。
  冲突食材可**同菜谱槽位一键替换**成其他在库食材（优先安全、优先有人爱吃、优先临期），
  或从计划中移除；用户也可勾选知悉风险后确认继续，确认依据随方案应用/计划创建写入追溯。
  食材详情页会汇总“家里谁需要避开这道菜”。
- **家庭共享补货清单**：手动添加待购食材（可填数量、备注和**可选负责人**），或在已吃完/已丢弃食材详情里
  一键补货（自动带出名称与分类）。待购项有**待认领 / 已认领 / 已购买**三种状态：谁顺路谁一键认领，
  也可转交给其他成员或取消认领；补货页可按状态筛选。添加时若发现同名在库食材会先提示、确认后才能加入。
  点「已买到」打开预填名称和分类的现有录入表单，**保存成功后**才标记已购买并关联新库存，取消录入则原样保留。
  认领、转交、取消认领与完成都会写入操作流水。
- **全程追溯**：字段修改有旧值快照、期限事件可撤销（历史保留）、删除可恢复，另有完整操作流水。
- **保存失败有提示**：数据只写本机浏览器，容量写满（小容量手机常见）时明确弹层告知「本次修改没有存进去」，
  表单内容保留可重试，并引导**先导出备份**、一键**清理历史痕迹**（只删较早的操作流水与字段快照，
  库存/事件/待购/计划/成员都不删，回收站恢复入口保留）；任何保存失败都会整体回滚，绝不出现“看似已存、刷新丢失”。
- **数据自主**：一键导出/导入 JSON 备份，清空数据不留下任何东西。

## 目录结构

```
index.html          页面（库存 / 补货 / 计划 / 方案 / 追溯五视图）
css/styles.css      手机优先样式
js/rules.js         20 类食材的保质期规则库
js/engine.js        纯决策引擎：期限重放、五档状态、建议、优先级、计划日调整提示
js/diet.js          家庭成员饮食偏好/忌口/过敏：标签匹配、冲突分级、替换安全性（纯函数）
js/planner.js       库存组合方案（8 个家常模板 + 丢弃/冷冻/复热处置 + 冲突食材同槽位替换）
js/ocr.js           拍照识别与标签文本解析
js/storage.js       本地存储、修订快照、审计流水、待购清单、用餐计划、家庭成员
js/app.js           界面渲染与交互
test/               单元测试与端到端冒烟测试
```

> 安全提示：本应用的期限为家庭场景的保守建议，不替代食品包装标注；
> 肉禽水产蛋奶豆制品及剩菜过期后，即使外观正常也建议丢弃。
